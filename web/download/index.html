怎样安装 · How to install

  1. 用手机的 Chrome 打开这一页，按「下载」。Open this page in Chrome on the phone and tap Download.
  2. 下载好按「打开」。第一次会问：允许 Chrome 安装未知应用 → 打开「允许」。Allow Chrome to install unknown apps when asked.
  3. 按「安装」。Tap Install.
  4. 打开 app，用同一个 email 和密码登录。没有账号就选「开新公司」或「加入公司」。Sign in with the same account, or create / join a company.

SuXin、POS、WMS、Every Data 这四个 app 会自动更新，不用重新下载；手机要装有 Chrome。SuXin Barcode Scan 有新版时要再下载一次安装。The first four update by themselves (Chrome is needed); download SuXin Barcode Scan again for a new version.
