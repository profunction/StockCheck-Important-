Feature breakdown

What's in the box

Scan anywhere

  • Phone camera or a USB / Bluetooth scanner
  • Works on Android and in the browser
  • Search by name when a label is missing

Count per location

  • Head office, warehouse and each shop counted separately
  • See which items have never been counted
  • Recount just the items that differ

Connected

  • Differences land in JSOX WMS
  • Same items and barcodes as the POS
  • Same email and password as every JSOX app

Managers
