一个系统，盘点、收银、库存都在里面

手机扫码盘点

用手机镜头扫条码，或用说的「五个鸡蛋」，或感应 NFC 标签。分区域盘点，自动加总。

电脑收银（POS）

USB 扫码枪、收据打印机（58/80mm）、分开付款、现金四舍五入到 5 仙、SST 含税或另加。

库存自动计算

库存 = 最后一次盘点 + 之后进货 − 之后卖出。每个数字都查得到来源，盘点后直接看到短少多少。

餐厅功能

桌位、堂食 / 外带、加料（甜度、加蛋）、厨房单、服务费。

进货和调货

供应商、采购单、收货、分店之间调货，全部自动进出库存。

会员和积分

会员卡（条码或 NFC），消费累积积分，下次可以抵钱。

多分店、员工权限

每间分店分开算库存；收银员不能改价、不能删收据，作废要写原因。

连接别的收银系统

Loyverse 自动同步商品、库存、销售，也可以写回盘点数量；其他 POS 用 Excel / CSV 导入。

报表

销售总结、按商品、分类、员工、付款方式、加料、折扣、税；可以导出 Excel。

开放 API

网店、会计软件可以用访问令牌读写商品、库存、收据和顾客。

常见问题

Pos Stock Check 支持 SST 吗？

支持。可以设定 SST 税率（例如 6% 或 8%），选择价格已含税或另外加，收据和税务报表会分开显示。

可以收 DuitNow QR 和刷卡吗？

可以记录 DuitNow QR、刷卡、电子钱包、现金和银行转账。系统记录付款方式和金额，钱照你平常的 QR 或刷卡机收，不经过系统。

现金会四舍五入吗？

会，按马来西亚的 5 仙规定：.01 和 .02 舍去，.03 和 .04 变 .05，.06 和 .07 变 .05，.08 和 .09 进位。刷卡和 QR 收到仙为止。

没有网络还能收银吗？

可以。没有网络时销售先存在电脑里，网络回来后自动上传。

需要买什么设备？

一台电脑或平板加 Chrome 就能用。建议加 USB 扫码枪和 58mm 或 80mm 热敏收据打印机。手机盘点用一般 Android 手机。

支持 NFC 和 RFID 吗？

支持。Android 手机可以感应 NFC 标签和会员卡；USB NFC 读卡器和 UHF RFID 手持机开「键盘模式」就能直接用。

我已经用 Loyverse，可以一起用吗？

可以。贴上 Loyverse 的访问令牌，就会同步商品、库存数量和销售；盘点后也可以把正确数量写回 Loyverse。

其他收银系统（StoreHub、Qashier 等）呢？

从你的收银系统导出销售报表（Excel 或 CSV），在 app 里导入，系统会自动认出每一栏。

资料安全吗？

资料存在 Google Cloud（Firebase）。每个员工只看得到自己权限和分店范围内的资料，每一次修改都有记录。
